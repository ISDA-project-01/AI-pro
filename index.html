Overview

This system integrates lightweight local LLMs through Ollama and provides a feature-rich workspace via Open WebUI. Designed specifically for standard CPU-only hardware with strict single-model active memory constraints.

Key Features

💬 Multi-Model Chat

Switch seamlessly between Llama 3.2 3B, Gemma 2 2B, Phi 3.5, Qwen2.5-Coder, DeepSeek-R1, OpenELM, Ministral, and SmolLM2 with automated memory unloading.

💻 Coding Assistant

Powered by Qwen2.5-Coder 3B for programming, debugging, code generation, and repository analysis.

📄 RAG & Documents

Upload PDF, TXT, DOCX, and source files for private document context retrieval.

🎙️ Voice & Tamil Speech

Whisper-base voice transcription and Tamil Text-to-Speech support using AI4Bharat / Facebook MMS-TTS.

🛠️ Secure Execution

Isolated Python code execution and safe terminal workflows with user confirmation controls.

🚫 No Image / Video Generation

Intentionally text and document focused. Image and video generation models are excluded to keep memory usage strictly under 8 GB.
