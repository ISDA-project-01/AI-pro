# Frequently Asked Questions (FAQ)

### Q: Can this run without a GPU?
**A**: Yes. The system and quantized models (1B-3B parameters) are explicitly configured for CPU inference on Windows 10.

### Q: Can I install all 8 models at once?
**A**: Yes. They reside on disk (~15 GB total). However, only **ONE** model will be loaded into RAM during chat execution.

### Q: Does it work offline?
**A**: Yes, 100% offline unless Web Search is enabled.
