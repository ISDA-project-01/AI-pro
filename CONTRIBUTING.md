# Contributing Guidelines

Thank you for your interest in contributing to the Local AI Assistant Platform!

## How to Contribute
1. Fork the repository.
2. Create a feature branch (`git checkout -b feature/new-tool`).
3. Ensure code quality and follow standard Python guidelines.
4. Test changes locally on CPU-only setup.
5. Submit a pull request.

## Code Standards
- Adhere to PEP8 style rules.
- Do not add heavy external frameworks. Keep dependencies minimal for 8 GB RAM targets.
