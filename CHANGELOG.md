# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2025-02-23

### Added
- Complete local AI assistant platform for Windows 10 (8 GB RAM / CPU-only).
- Ollama and Open WebUI integration controller.
- Support for 8 local LLM models (Llama 3.2, Gemma 2, Phi 3.5, Qwen2.5-Coder, DeepSeek-R1, OpenELM, Ministral, SmolLM2).
- Enforced single-model active memory management.
- Local RAG, document handling, and persistent memory.
- Safe code execution and terminal manager.
- Optional Whisper voice transcription and Tamil TTS synthesis.
- Health check and system monitoring scripts.
- PowerShell and batch launcher scripts (`setup.ps1`, `setup.bat`, `start.bat`, `stop.bat`).
